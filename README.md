# SEU HOTEL — Concierge Digital

Versão com identidade visual cinza azulado, branco, preto e dourado.

## Atualização no GitHub Pages
1. Extraia este ZIP.
2. Envie todos os arquivos desta pasta para a raiz do repositório, mantendo os nomes.
3. Substitua o `index.html` existente e mantenha os quatro arquivos de imagem junto dele.
4. Confirme o commit na branch/pasta usada pelo GitHub Pages.
5. Após a publicação, atualize o site com Ctrl + F5.

O conteúdo das 11 seções, links, identificadores, funções JavaScript e ações do concierge foram mantidos em relação à versão profissional anterior.
